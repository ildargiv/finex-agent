FinEx

ИИ-агент для держателей фондов FinEx: следит за документами ликвидатора, суда и регуляторов, собирает новости и форумы, проверяет слухи и считает, сколько может прийти на пай в сравнении с ценой и предложениями выкупа.

Возможности

Что умеет агент

Портфель

Импорт ISIN и количеств из отчёта депозитария или брокера (.ods/.xlsx/.csv) либо ручной ввод. ФИО и номер счёта не читаются.

Документы

finexetf.com, страницы ликвидатора, ЦБ Ирландии, Мосбиржа, НРД: новые PDF скачиваются и пересказываются.

Новости

Google News на русском и английском по ликвидации FinEx, пометка существенного.

Форумы и Telegram

Smart-Lab и публичные каналы; сообщения из закрытых групп — через «входящие» с проверкой.

Выплата против рынка

СЧА → резерв, комиссия, расходы, замороженные активы → дисконт за срок → рубли по курсу ЦБ. Три сценария.

Приватность

Всё хранится только в ~/finex-desk на вашем компьютере.

Живые данные

Так выглядит расчёт выплаты

Реальный вывод payout.py на допущениях по умолчанию. СЧА нормирована к 100 USD для наглядности: агент берёт настоящую СЧА из фактшитов и отчётности фонда.

$ python payout.py nav FXUS 100 --ccy USD --date 2026-11-07 --source "демо: СЧА нормирована к 100"
$ python payout.py FXUS
# Выплата vs рынок — 2026-11-07
Курсы ЦБ на 07.11.2026: USD 82.14, EUR 92.19. Ставка дисконтирования 7.0% год.
FXUS | СЧА 100.0000 USD | выплата/пай ₽: пессим. 5 772.45 / базовый 6 734.58 / оптим. 7 613.05
Разложение для FXUS (в USD на пай, до дисконтирования):
- пессим.: резерв 8.50% = −8.5000; комиссия погашения 3.00% = −2.7450; расходы 3.00% = −2.6626 → 86.0923; через 3.0 г. по 7.0% → 70.2770
- базовый: резерв 5.50% = −5.5000; комиссия погашения 3.00% = −2.8350; расходы 1.00% = −0.9167 → 90.7484; через 1.5 г. по 7.0% → 81.9904
- оптим.: резерв 2.00% = −2.0000; комиссия погашения 0.00% = −0.0000; расходы 0.50% = −0.4900 → 97.5100; через 0.75 г. по 7.0% → 92.6854
Модель, а не обещание: ликвидаторы не публиковали сумму на пай; выплаты держателям через НРД — только после санкционных разрешений.
Установка

Одна команда для каждой среды

Навык по открытому стандарту Agent Skills (SKILL.md). Нужен Python 3.9+, только стандартная библиотека и pypdf для PDF.

$ git clone https://github.com/ildargiv/finex-agent.git && cd finex-agent
$ ./install.sh claude
